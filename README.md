# Sada's intro to Python foundation

A single-file revision website for the Introduction to Programming with Python sprint.

## 🌐 Live website

**https://sadasantosh.github.io/sadas-intro-to-python-foundation/**

Open that link in any browser — no install, no sign-in. It works for anyone with the link.

## What's inside

- **539 questions** across 4 modules and 15 topics (theory, code tracing, debugging, writing)
- **Important only / All questions** filter, plus per-topic levels
- **Mistake practice** — retry questions you got wrong without resetting anything
- **Progress dashboard** — auto-graded and self-marked accuracy per module and topic
- **Bookmarks and notes** — star questions and keep plain-text notes
- **Search** — find questions by id, title, prompt, module or topic, and copy a direct link
- **Export / import** — versioned JSON backup of your progress

Light and dark themes, keyboard accessible, mobile friendly.

## Notes

- Your answers, bookmarks and notes are saved in **your own browser** (local storage). Nothing is uploaded.
- Progress is per browser and per device; use **Study tools → Export / import** to move it.
- The site is a single `index.html`, served by GitHub Pages from the `main` branch root.
